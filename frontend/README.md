# VoyageAI Frontend

VoyageAI is an **AI-powered travel planning application** that helps users discover destinations, save favourites, create personalized trips, and get AI-powered travel recommendations.

This repository contains the frontend of VoyageAI built with **React, Vite, and Tailwind CSS**.

---

## 🌐 Live Demo

🚀 https://voyage-ai-frontend-beta.vercel.app/login

## 🚀 Features

- 🔐 User Authentication
- 🏠 Interactive Dashboard
- 🌍 Explore Trending Destinations
- ❤️ Favourite Destinations
- 🖼️ Dynamic Destination Images using Pexels API
- 🧳 Create & Manage Trips
- 📋 View All Created Trips
- 🤖 AI-Powered Trip Planning
- 💬 AI Travel Assistant
- 💰 AI-Based Travel Budget Estimation
- 📱 Fully Responsive Design

## 🤖 AI Features

VoyageAI provides AI-powered travel features through the backend.

### AI Trip Planning

Users can enter their trip details such as:

- Source
- Destination
- Travel dates
- Number of travellers
- Travel mode
- Budget

VoyageAI then generates personalized travel recommendations including places, food, stay areas, transportation, activities, estimated costs, and travel tips.

### 💬 AI Travel Assistant

Users can also directly chat with the **VoyageAI Assistant** to ask travel-related questions.

Quick suggestions include:

- 🧘 Peaceful
- 🏔️ Adventure
- 🏖️ Beach
- 🏔️ Mountain
- 💸 Budget

Users can also type their own questions and get personalized travel suggestions.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/VoyageAI-Frontend.git
```

Move into the project directory:

```bash
cd VoyageAI-Frontend
```

Install dependencies:

```bash
npm install
```

Create a `.env` file:

```env
VITE_BACKEND_URL=http://localhost:5000
```

Run the development server:

```bash
npm run dev
```

The application will run on the local Vite development server.
